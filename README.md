# 🍰 Sweet Recipes Website

Welcome to the **Sweet Recipes Website** – a simple and attractive website where you can explore delicious sweet recipes. 🍪🧁🍫

This project is designed to provide users with an easy way to discover different desserts along with their ingredients and preparation methods.

## 🌸 Features

- 🍰 Collection of delicious sweet recipes
- 🧁 Simple and attractive user interface
- 🍫 Easy-to-follow recipe instructions
- 🍪 Ingredients listed for each recipe
- 📱 Responsive website design
- 🎨 Clean and user-friendly layout
- 🔍 Easy navigation between recipes

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
